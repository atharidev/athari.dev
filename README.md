# athari.dev

The personal homepage at [athari.dev](https://athari.dev): software, AI and cloud, business development, consultancy, open source, and community.

A lightweight static site served from the repository root by GitHub Pages. No framework, build step, analytics, or project listing. The collaboration form delivers enquiries through FormSubmit.

- `index.html`: semantic page content and social metadata
- `style.css`: responsive layout, typography, motion, and accessibility preferences
- `site.js`: artwork controls, pointer interaction, visibility handling, and footer year
- `assets/ripple.svg`: original mathematical wire sculpture
- `assets/manrope.woff2`: self-hosted Manrope typeface (see its OFL license)
- `og.png`: social preview
- `favicon.svg`: site mark
- `CNAME`: existing custom domain

- `contact.js`: isolated contact form enhancement, no local storage or embedded credentials
- `thank-you.html`: fallback confirmation page for native form submissions

Push to `main` to publish through the existing GitHub Pages setup. All content and navigation remain usable without JavaScript. Motion honors the system reduced-motion preference and can be paused. Animations pause off screen and in background tabs.


## Collaboration enquiries

The form sends creator/business selection, email and an optional brief to adam@athari.dev via FormSubmit. No mailing list or automatic response to visitors. One-time recipient activation is required through the FormSubmit email sent after the first submission. FormSubmit documentation states submissions are retained for 30 days. The provider privacy link is beside the form. Native POST remains available without JavaScript; enhanced submissions show inline sending, error and success states, retain fields on uncertain delivery, and prevent simultaneous duplicate requests. A hidden honeypot supplements provider filtering. No subscriber database is created.
